# 测试指南

## 1. 编译检查

在项目根目录运行：

```powershell
gradle :app:assembleDebug
```

需要 Android 静态检查时运行：

```powershell
gradle :app:lintDebug
```

APK 输出：

```text
app/build/outputs/apk/debug/app-debug.apk
```

编译警告需要记录并评估；新增代码不得引入未说明的警告。

## 2. ADB 准备

查看设备：

```powershell
adb devices
```

安装或覆盖升级：

```powershell
adb -s <设备序列号> install -r app/build/outputs/apk/debug/app-debug.apk
```

启动：

```powershell
adb -s <设备序列号> shell am start -n com.ane.filemanager/.MainActivity
```

强制停止后重启，用于验证持久化：

```powershell
adb -s <设备序列号> shell am force-stop com.ane.filemanager
adb -s <设备序列号> shell am start -n com.ane.filemanager/.MainActivity
```

MuMu 的 ADB 地址依本地配置而定，当前常用示例是 `127.0.0.1:16384`。不要在代码或产品逻辑中依赖这个地址。

## 3. 测试数据

- 所有截图、测试图片、视频、音频、文本和临时文件放在 `testphoto/`。
- 不在项目根目录放测试媒体。
- 删除、移动和撤回测试只使用明确创建的测试文件，禁止拿用户真实文件试验。
- 截图命名应描述场景，例如 `fab-delete-selected.png`、`dock-reorder-cancel.png`。

## 4. 主页面回归

### 布局与适配

- 列表和网格模式均能滚动并具有惯性。
- 字体、图标和行间距设置立即生效。
- 窄窗口不会导致地址文字、菜单或对话框溢出和闪退。
- 深浅色模式下文字、阴影、缩略图和浮动按钮对比度正常。
- 状态栏、导航栏、刘海和 DeX 任务栏不遮挡内容。

### 选择与输入

- 单击选中，系统双击时间内第二次点击打开。
- 多选模式下单击只切换选择，不打开文件。
- 滑动选择与普通纵向滚动不会互相误触。
- 长按达到系统阈值后出现震动和视觉反馈。
- 长按后原地松手显示菜单；移动超过系统 touch slop 后进入拖动。
- 鼠标右键不会因 DeX 的重复事件打开两次菜单。
- 桌面快捷键和地址输入不会互相抢占。

### 标签栏

- “存储”固定在最左侧。
- 固定标签、临时标签和当前标签显示正确。
- 切换到其他标签后临时标签不会自动消失。
- 长按标签进入标签编辑，而不是复用文件选择状态。
- 标签拖动只交换顺序，不移动文件夹。
- 拖动到取消区域有反馈并且顺序不变。
- 长标签栏可以横向滚动，长名称从开头开始连续向左滚动。

### 文件事务

- 新建文件和文件夹。
- 重命名单个项目。
- 复制、剪切和粘贴到当前目录。
- 将文件拖动到目标文件夹。
- 删除后可连续撤回多步，不限制为一步。
- 同名、权限不足、源文件消失和目标位于源目录内部时显示正确错误。
- 执行文件任务时界面显示忙碌状态，完成后恢复。
- Activity 销毁时不崩溃、不更新旧界面，也不强制中断正在进行的事务。

## 5. 查看器回归

### 图片

- 左右滑动切换同目录图片。
- 双指缩放围绕手势中心，缩放时不误切换。
- 大图加载不会阻塞主线程或导致明显内存峰值。

### 视频和音频

- 播放、暂停、拖动进度和上一个/下一个正常。
- 切换文件后标题、位置和播放器状态更新。
- 切到后台会暂停并保存合理的恢复位置。
- 离开 Activity 后播放器被释放。

### 文本

- UTF-8、带 BOM 文本及常见编码可以读取并保持编码保存。
- TXT、Markdown、XML 等文件输入跟手。
- XML/HTML 高亮防抖不会阻塞输入。
- 编辑区具有惯性滚动。
- Tab、Shift+Tab 和多行缩进正确。
- 未保存退出时出现确认对话框。

## 6. 持久化与升级

分别验证以下流程：

1. 普通返回桌面后重新进入。
2. `force-stop` 后重新进入。
3. 使用 `adb install -r` 覆盖升级后进入。
4. 完全结束进程后进入。

每次都检查标签顺序、固定状态、临时标签、活动目录和历史。撤回栈不要求跨进程保留；旧回收目录会在新会话启动时清理。

## 7. 真机检查

模拟器通过后至少在一台真机验证：

- 手指长按和震动反馈。
- 滑动惯性与双指缩放。
- 系统字体缩放和显示缩放。
- 横竖屏、分屏和自由窗口尺寸。
- 鼠标右键、键盘 Tab 和 DeX 任务栏。
- 安装升级后的标签持久化。

真机验证发现的比例问题应回到响应式布局计算解决，不得增加机型或分辨率特判。
